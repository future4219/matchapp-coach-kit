# matchapp-coach-kit

マッチングアプリのやり取りを **Claude Code** と一緒に記録・分析して、**自分専用の返信スタイル**を育てていくためのテンプレート。

- スクショを送ると、自分のキャラ・口調に合わせた返信案が出る
- 送ったメッセージと相手の反応を記録して、どの型が効いているかを集計する
- データから言える改善は、Claudeが返信スタイルの修正プルリクとして出す（採用するかは自分で決める）

設定は **Claudeと話しながら** 作れる。ファイルを手で書く必要はない。

## はじめかた

1. このリポを **テンプレートとして使い、必ず Private（非公開）で** 自分のリポを作る
   （GitHubの「Use this template」→ Visibility を **Private**）
2. 作ったリポで Claude Code を開く
3. 「セットアップしたい」と言う（言わなくても、未設定なら Claude から提案してくる）
4. 5ステップの質問に答える（10分くらい）
   1. 呼び名・Claudeの話し方・使ってるアプリ・ゴール
   2. 自分のプロフ（スクショでOK）
   3. 返信スタイル（キャラ、口調、うまくいった実例、序盤の型、NG）
   4. 記録に使う段階と型
   5. 確認・ロープレで試す

あとから変えたいときは「設定変えたい」と言えばいい。

## 使い方

| 言うこと | 起きること |
|---|---|
| （トークやプロフのスクショ）＋「返信どうする？」 | 返信案が出る |
| 「これ送った」 | ログに記録される |
| 「状況」「一覧」 | 相手ごとのボールの状況が表で出る |
| 「ロープレしよ」 | Claudeがあなた役、あなたが相手役で練習 |
| 「分析して」 | レポートと、スタイル改善のプルリクが出る |

## 中身

```
CLAUDE.md                         Claudeへの運用ルール（共通）
.claude/skills/matchapp-setup/    会話で設定を作るスキル
.claude/skills/matchapp-reply/    返信案を出すスキル（共通ルール）
.claude/settings.json             起動時にセットアップ状況を確認するフック
config.example/                   設定の雛形
config/                           あなたの設定（セットアップで作られる）
  profile.md                      呼び名、話し方、ゴール
  me.md                           自分のプロフ
  style.md                        返信スタイル（分析で育つ）
  settings.json                   段階と型の一覧
data/matches/                     相手ごとのメモ
data/messages.jsonl               送ったメッセージと結果のログ
data/roleplay/                    ロープレの記録
reports/                          分析レポート
scripts/                          集計スクリプト（Python 3、標準ライブラリのみ）
```

## ルール（これは設定で変えられない）

- **送信は必ず自分の手で。** Claudeは案を出すだけ。アプリの自動操作は規約違反でアカウント停止になる
- **写真は保存しない。** スクショはテキストだけ記録して捨てる（画像は `.gitignore` 済み）
- 相手は表示名かイニシャルで管理。本名・ID・勤務先・住所など、特定できる情報は書かない
- **自分のリポは必ず非公開で。** 相手とのやり取りが入る
- 嘘で相手をだます案、断られても押す案は出さない
