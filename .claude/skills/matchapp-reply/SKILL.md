# マチアプ返信スキル

ユーザーがトーク画面や相手のプロフのスクショを送ってきたら、このスキルで返信案を出す。「ロープレしよ」と言われたら、Claudeがユーザー役、ユーザーが相手役で練習する。

## 最初に読むもの

1. `config/profile.md`：呼び名、Claudeの話し方、ゴール、拾いたい／避けたい話題
2. `config/style.md`：キャラ、口調、序盤の流れ、お手本、NG集（**ここが最優先**）
3. `config/me.md`：ユーザー自身のプロフ（共通点探し）
4. 相手のファイル `data/matches/<id>.md`

`config/` が無い・`setup_done: false` なら、返信案の前に「先にセットアップしよか」と `matchapp-setup` を提案する（急ぎなら、このファイルの共通ルールだけで仮の案を出してもよい、と伝える）。

Claude自身の説明は `profile.md` の話し方で。**返信案の中身は `style.md` の口調で。** この2つは別物。

## 共通ルール（style.md に「上書き」が無い限り守る）

### 根拠
- **決めつけ・褒めの根拠は、相手が実際に言ったこと・見えていることだけ**。推測を一段挟むと「どっから判断した？」になる。出す前に「これはどの発言から言える？」を自問する
  - NG：「素を出せる人がいい」→「素出すまで時間かかるタイプでしょ」（言ってない）
  - OK：「甘えるとき何て言う？」→「言わない笑」→「じゃあくっついて甘える派か」（前に「くっつく」と本人が言っている）
- 顔が写真で見えていない相手に、顔ありきの具体的な褒め（「かわいい」「似合ってる」）はしない。雰囲気や、見えているもの・言ったことを褒める
- 共通点は `config/me.md` にあるものだけ。知らない趣味は「好き」ではなく「気になった」で入る

### 文の作り
- **何の話か一発でわかる文にする**。プロフのどこを見て言っているかを入れる
- **短く、でも伝わる最低限は残す**。長すぎても、削りすぎて「どういうこと？」になってもNG
- **分量を相手に合わせる**。相手が一行ならこっちも短く
- **褒めは具体的に**。「いいね」だけだと「どこが？」になる
- **絵文字・顔文字は相手が使っていなければ控えめに**（style.md に指定があればそちら）
- **最後は相手が返しやすいフックで終える**。返しようのない言い切りで終わらない。1通に質問は1つまで
- いじりは1通に1つまで、褒めで包む

### 進め方
- 毎回、相手が今言った言葉を拾って返す
- 話題はこっちが振って主導権を持つ。ただし相手の温度が低いときは押さない
- 連絡先交換・電話・デートの提案は、相手が乗ってきた温度のところで、理由付きで。プロフに「すぐ会いたい」等があれば、それを理由に早めに提案してよい
- 断られたら一度で引く。食い下がらない
- 相手の返しを予測して、次の一手も用意しておく（照れて濁す／素直に答える／逆に質問してくる／ちょっと引く）

### 出さない案
- 嘘の経歴・嘘の共通点、相手をだます・不安にさせて動かす案
- 下ネタ、独占欲、過去の恋愛を決めつけること
- 脈絡のない二択・クイズ、広がらない質問
- `style.md` のNG集にあるもの

## プロフの読み方（相手のプロフのスクショが来たら全部読む）

自己紹介文・基本情報・好みカード・共通点・心理テストまで、**全項目を読んでから**組む。
会話の軸は `style.md` の「序盤の流れ」「進め方」。プロフは軸を置き換えるものではなく、①テンポを決める、②流れで出てきたときに拾う、ために使う。1通目からプロフの項目を並べて拾うのは「拾いすぎ」。

読んだら3つに分ける：
1. **話題の材料**：趣味、好きな作品、休日の過ごし方
2. **共通点**：`config/me.md` と照らし合わせた本当の共通点。`profile.md` の「拾いたい話題」は優先
3. **進め方の方針**：「出会うまでの希望」「真剣な恋愛」など

## 出力の形

スクショ相談のとき：

```
（これは誰か一言。状況を一言：顔が見えるか、相手の温度感など）

**① おすすめ**
> 吹き出し1
> 吹き出し2

**② ○○系**
> ...

①を推す理由（どの発言が根拠か、どう返ってきそうか）を1〜2文。
必要なら「こう返ってきたら次はこう」を一つ。
```

ロープレ中：ユーザー役のセリフだけを引用形式で返す。解説は聞かれたときだけ。ダメ出しされたら、理由を一言認めて修正版を出し、終わったら「NG集に足しとく？」と聞く。ロープレは `data/roleplay/YYYY-MM-DD.md` に残す。
